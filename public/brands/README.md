# Provider artwork

These self-hosted assets identify the sign-in providers. They are separate from the garden's original pixel sprites.

- `google.png`: unmodified Google sign-in G from [Google Identity branding assets](https://developers.google.com/static/identity/images/g-logo.png). See [branding guidance](https://developers.google.com/identity/branding-guidelines). Keep its colors and aspect ratio, on the white sign-in button.
- `github.svg`: unmodified GitHub mark from [GitHub's Primer Octicons](https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-16.svg). See [Octicons license](https://github.com/primer/octicons/blob/main/LICENSE) and [GitHub branding guidance](https://brand.github.com/foundations/logo). Keep its shape and use it only to identify the GitHub integration.

Brand trademarks belong to Google and GitHub respectively; this app does not imply endorsement.
